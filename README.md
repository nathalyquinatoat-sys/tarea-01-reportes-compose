# Tarea 01: Reportes con Jetpack Compose

## Descripción
Aplicación Android desarrollada con Kotlin y Jetpack Compose como parte de la actividad práctica.

## Funcionalidades
- Tarjeta de presentación personalizada.
- Tarjetas de reportes con ubicación, prioridad y estado.
- Asignación de colores según la prioridad.
- Pantalla que muestra el listado y total de reportes.
- Registro de advertencias mediante Logcat.

## Tecnologías utilizadas
- Kotlin
- Android Studio
- Jetpack Compose
